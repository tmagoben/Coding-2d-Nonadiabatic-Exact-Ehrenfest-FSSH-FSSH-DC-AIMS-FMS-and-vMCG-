# v0.13 Residual-Driven Basis Campaign

This file explains exactly how to reproduce the release benchmark and what each stage
is testing.

## 1. Read first

Before running the campaign, read:

```text
V13_THEORY.md
V13_DERIVATIONS.md
V13_VALIDATION.md
```

The key distinction is:

```text
initial projection residual
        !=
instantaneous TDSE defect
```

The first builds the initial bank.

The second diagnoses missing dynamical tangent directions after a state has already
been represented.

## 2. Candidate dictionary

The release dictionary is generated by:

```python
from gaussian_dynamics import (
    cartesian_offsets_2d,
    generate_gaussian_dictionary,
)

candidates = generate_gaussian_dictionary(
    q0,
    p0,
    A0,
    state,
    cartesian_offsets_2d(
        radius=1.0,
        spacing=0.2,
    ),
    width_scales=(
        1.0,
        1.5,
        2.0,
        3.0,
        4.0,
        6.0,
    ),
)
```

No momentum offsets are used in the release dictionary.

The purpose is to isolate center/width basis completeness.

## 3. Why the dictionary is precomputed

The release uses:

```python
prepare_gaussian_dictionary(...)
```

to evaluate all candidate nuclear Gaussian functions on the diagnostic grid once.

Then every residual-gain iteration is evaluated with dense NumPy matrix products.

This changes performance, not the mathematics.

A unit test verifies that the vectorized implementation selects the same pure
residual-greedy candidates as the direct implementation on a controlled dictionary.

## 4. Seed state

The initial basis contains one Gaussian at:

```text
q = q0
p = p0
A = A0
guidance state = upper adiabatic state
```

Every additional candidate is selected from the documented dictionary.

## 5. Pure residual-greedy run

Run:

```python
build_residual_greedy_basis_prepared(
    target_psi,
    points,
    dx,
    provider,
    [seed],
    prepared_dictionary,
    max_basis=11,
    top_k_density_screen=1,
    density_screen=False,
)
```

At every step:

1. project the target wavefunction;
2. compute the residual;
3. calculate every candidate's orthogonal norm;
4. calculate its exact one-step residual gain;
5. reject candidates that violate conditioning;
6. add the largest-gain candidate;
7. reproject;
8. verify the residual decreased.

## 6. Density-screened residual reference

The release reference uses:

```python
top_k_density_screen = 30
density_screen = True
```

At each step:

1. rank all candidates by Hilbert residual gain;
2. retain the top 30;
3. compute the one-step trial projection for those candidates;
4. compare only their **initial** reduced electronic density errors;
5. choose the smallest density error;
6. use wavefunction residual, conditioning, and gain as deterministic tie breakers.

No final-time exact result is available to this selection process.

## 7. Full projection ladder

The saved campaign records every selected basis size from 1 through 11.

Inspect:

```text
projection fidelity
relative wavefunction residual
initial reduced-density error
overlap condition number
selected candidate
predicted residual gain
actual residual reduction
```

The wavefunction residual must decrease monotonically.

The reduced-density error is not required to do so at every intermediate basis size.

## 8. Representation-consistent propagation

After the 11-Gaussian bank is complete:

1. save the projected initial wavefunction;
2. propagate that projected wavefunction with the exact 2D TDSE;
3. propagate the same projected state with exact-LVC Gaussian dynamics;
4. compare the final reduced electronic densities.

This produces the projected-state dynamics error.

Only after that comparison is complete do we compare against the original intended
exact target state.

## 9. TDSE-defect enrichment

At the initial v0.13 projected state:

```python
defect = compute_tdse_defect(
    coefficients,
    basis,
    provider,
    grid,
)
```

Then:

```python
result = enrich_basis_from_tdse_defect(
    coefficients,
    basis,
    provider,
    grid,
    candidates,
)
```

The selected Gaussian enters with:

```text
electronic coefficient 0 = 0
electronic coefficient 1 = 0
```

Therefore the wavefunction at the enrichment instant is unchanged.

The coefficient derivative is then recomputed in the larger Galerkin space.

## 10. What to verify in the defect test

Compare:

```text
defect norm before
defect norm after
predicted squared reduction
actual squared reduction
candidate capture fraction
expanded condition number
```

The predicted and actual squared reductions should agree within the configured
numerical tolerance.
