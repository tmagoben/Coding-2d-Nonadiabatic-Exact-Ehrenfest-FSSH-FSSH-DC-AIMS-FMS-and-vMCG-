# Historical version documentation

This directory preserves the design notes, derivations, validation records, benchmark
reports, and release notes for earlier Gaussian Dynamics versions. These folders are
documentation snapshots, not separate active GitHub releases.

The sole certified release is **v0.27.0**. Its current documents remain at the
repository root, beginning with [`V270_RELEASE_NOTES.md`](../../V270_RELEASE_NOTES.md).
Development-version documents, when present on `develop`, also remain at the root until
that version is certified.
