# v0.10 Validation Contract

## Cumulative regression

All v0.1-v0.9 tests must remain passing.

## Wigner ensemble

- analytic coordinate covariance is $\frac12A^{-1}$;
- analytic momentum covariance is $\frac12A$;
- seeded samples are bitwise/reproducibly generated by NumPy's selected RNG path;
- large synthetic samples reproduce means and covariances within statistical
  tolerance.

## Reduced electronic observables

- exact-grid reduced density has trace equal to the grid norm;
- a unitary fixed-frame rotation preserves trace and density eigenvalues;
- one graph TBF produces a normalized pure reduced state;
- graph reduced-density trace agrees with the generalized norm before normalization;
- normalized reference-frame populations sum to one.

## Exact-reference campaign

- every exact surface point conserves norm;
- populations sum to one;
- finest-reference selection is deterministic;
- the selected row is not described as mathematically converged until neighboring
  refinement differences are inspected.

## Managed parameter surface

- Cartesian-product case count is deterministic;
- every row records timestep, SPA order, spawn action, maximum basis size, and
  overlap-block threshold;
- old v0.9 behavior is preserved unless repeated spawning is explicitly enabled.

## Benchmark acceptance

- conservation, conditioning, pruning loss, and exact-reference accuracy are separate
  checks;
- a run fails if any requested acceptance criterion fails.

## Error budget

- each component is a normed sensitivity difference;
- the dominant reported axis is the largest numerical proxy;
- components are never added as if they were independent statistical errors.

## Ensemble statistics

- mean, unbiased standard deviation, and SEM follow their standard definitions;
- $N=1$ returns zero estimated sample variance rather than dividing by zero.

## Scientific comparison rule

The exact and Gaussian calculations must compare the same observable.

For graph calculations this release prefers a reduced electronic density matrix in a
common fixed electronic frame over the older local-state-label population proxy.
