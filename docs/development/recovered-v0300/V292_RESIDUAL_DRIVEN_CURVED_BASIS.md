# v0.29.2 Residual-Driven Curved Basis Adaptation

## Status
Development checkpoint. It does not replace the certified v0.27.0 release.

## New variational decision rule
Let `J` contain every current real TDVP tangent and let `K_c` contain the electronic coefficient tangents of a candidate curved Gaussian section. With quadrature metric `W`,

\[
M=\Re(J^\dagger WJ),\quad X=\Re(J^\dagger WK_c),\quad C=\Re(K_c^\dagger WK_c).
\]

The genuinely new candidate tangent space is

\[
S_c=C-X^TM^+X.
\]

For the current TDSE defect \(r=\dot\Psi+iH\Psi\), define

\[
g=\Re(J^\dagger Wr),\quad q_c=\Re(K_c^\dagger Wr),\quad y_c=q_c-X^TM^+g.
\]

The predicted instantaneous squared-defect reduction is

\[
\Delta_c=y_c^TS_c^+y_c.
\]

This prevents spawning a packet merely because its coefficient functions are novel: a packet is useful only if it adds a direction not already generated by coefficient, center, momentum, width, chirp, and Wilson-center tangents.

## Curved candidate section
Each candidate carries the same straight Wilson convention as v0.29.1,

\[
\Phi_{c,a}(R)=g_c(R)L_c(R)e_a,\qquad
L_c(R)=\exp[-(R-q_c)^\mu D_\mu].
\]

## Topology change
Accepted topology changes use a full-SVD projection of the complete curved wavefunction. A spawn therefore inserts an exactly zero-amplitude packet up to quadrature/SVD precision; its coefficient block may evolve immediately while its shape remains subject to the inherited newborn activation gates.

## Inherited safety policy
- one event per checkpoint;
- event order merge, prune, spawn, no-op;
- correlated principal-axis candidates;
- degenerate-width eigenspaces fail closed;
- overlap/conditioning/projection gates remain mandatory;
- newborn population, metric-condition, and velocity-amplification gates remain mandatory;
- no-event path is an exact object-level reduction.

## Explicit non-claims
No coordinate-dependent connection, arbitrary path family, patch transition, live molecular NAC/SOC provider, multi-event AIMS branching, ML spawning policy, or nuclear-spin dynamics is claimed.
