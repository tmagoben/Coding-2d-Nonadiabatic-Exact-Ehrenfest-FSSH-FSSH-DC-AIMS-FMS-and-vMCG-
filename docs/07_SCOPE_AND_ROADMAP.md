# Scope and roadmap

## v0.23.3 capabilities

v0.23.3 supports all v0.23.2 capabilities plus:

- separate raw finite-manifold contractions and unitary polar transports;
- independent physical-consistency and trajectory-readiness overlap gates;
- replay format 2 with singular values, transport, policies, and NAC identity;
- evidence-bound legacy migration with unknown/wrong-sign NAC quarantine;
- complete singlet/triplet and Kramers-doublet transport under endpoint gauges;
- a frozen SOC matrix/prefactor/state-order/unit/derivative convention;
- convention-complete provider identity for replay, cache, and checkpoint paths;
- separate canonical release-lock and scientific-compatibility runtime profiles;
- a deterministic 208-gate acceptance campaign.

The release inherits:

- an installed, hash-locked, content-verified PySCF 2.13.1 runtime;
- real spin-free H3+ SA-CASSCF energies and analytic gradients;
- real SA-CASSCF NACs certified against phase-aligned many-electron overlap
  finite differences at three displacement sizes;
- corrected PySCF state-tuple orientation and explicit ETF/full-overlap separation;
- finite selected-manifold overlap contractions with quantitative retention
  diagnostics;
- exact runtime, method, parser, execution, receipt, dossier, and replay bindings;
- structure-first engine validation, callable methods, seven-stage convergence,
  and caller-anchored trusted validator types;
- the deterministic 168-gate v0.23.2 acceptance campaign.

The inherited framework retains physical analytic SOC for complete even-electron
singlet/triplet and odd-electron Kramers-doublet model spaces, complex U(s)
covariance, block-sparse Gaussian dynamics, exact-grid comparison, adaptive
lifecycle controls, and deterministic restart.

## v0.23.3 exclusions

v0.23.3 does not include or claim:

- an admitted external ab-initio SOC snapshot;
- an admitted live molecular-SOC backend;
- a live PySCF SOC runtime or molecular-SOC accuracy;
- a complete PySCF method-specific state-interaction SOC implementation;
- external magnetic fields or production AIMS scheduling.

## Completed milestone: transport and compatibility hardening

The v0.23.3 gate now:

1. keeps raw overlap evidence distinct from unitary coefficient transport;
2. rejects rank loss, norm expansion, inadequate retention, and broken reciprocity;
3. versions replay/NAC semantics and refuses implicit legacy loading;
4. quarantines ambiguous or known-wrong NAC signs;
5. binds all numerical conventions into provider/checkpoint identity;
6. tracks complete even- and odd-electron manifolds covariantly;
7. freezes the molecular-SOC matrix and derivative convention;
8. separates byte-locked and scientifically compatible runtime claims;
9. preserves the distinct external-snapshot and fresh-live paths;
10. preserves all 168 v0.23.2 gates in a 208-gate campaign.

## Recommended next milestone: method-specific molecular SOC

The next release should integrate one named method-specific state-interaction SOC
implementation on a named reference molecule. It must provide:

1. a documented SOC Hamiltonian, prefactors, scalar-relativistic treatment,
   active space, basis, charge, electron parity, and complete state order;
2. physical spin-free and SOC derivatives for every trajectory coordinate;
3. complete singlet/triplet or Kramers manifolds and time-reversal data;
4. many-electron overlaps and finite-manifold tracking across geometries;
5. raw inputs/outputs plus a typed parser that reconstructs replay arrays;
6. independent reference data and basis/method convergence ladders;
7. translation/rotation controls and derivative finite differences;
8. a passing external-snapshot admission before enabling live propagation;
9. a separately challenged fresh-execution proof before live admission.

PySCF core is a validated spin-free foundation, but it is not treated as a
turnkey source of these method-specific SOC quantities.

## Longer-term milestones

After one real SOC source is admitted, later releases may add multi-coordinate
molecular benchmarks, sparse overlap-graph replay, recovery and asynchronous
scheduling, magnetic-field symmetry contracts, and production AIMS branching.
Each requires a separate validation claim.
