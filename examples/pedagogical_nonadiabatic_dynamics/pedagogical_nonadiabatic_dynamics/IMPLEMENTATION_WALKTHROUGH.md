# Annotated Python Implementation Walkthrough

This document should be read after `DYNAMICS_TUTORIAL.md`. The theory document
derives the equations; this document maps each mathematical operation to the
corresponding Python operation.

---

## 1. Construct a periodic FFT grid

```python
from nonadiabatic_dynamics import PeriodicGrid1D

grid = PeriodicGrid1D.create(
    n=256,
    x_min=-20.0,
    x_max=20.0,
)
```

The returned arrays satisfy

```python
grid.dx == (20.0 - (-20.0)) / 256
grid.x.shape == (256,)
grid.k.shape == (256,)
```

`grid.k` is generated by

```python
2.0 * np.pi * np.fft.fftfreq(n, d=dx)
```

and is ordered exactly as required by `numpy.fft.fft`.

---

## 2. Construct the matrix-valued avoided-crossing potential

```python
from nonadiabatic_dynamics import smooth_single_avoided_crossing

potential, potential_derivative = smooth_single_avoided_crossing(
    grid.x
)
```

The array shapes are

```python
potential.shape == (256, 2, 2)
potential_derivative.shape == (256, 1, 2, 2)
```

At grid point `n`, `potential[n]` is the complete electronic potential matrix

$V_{\mathrm{d}}(x_n)$.

The coordinate index in `potential_derivative[:, 0]` is $x$.

---

## 3. Obtain adiabatic energies and phase-tracked eigenvectors

```python
from nonadiabatic_dynamics import diagonalize_path

adiabatic_energies, adiabatic_vectors = diagonalize_path(potential)
```

At every point,

```python
potential[n] @ adiabatic_vectors[n]
```

equals

```python
adiabatic_vectors[n] @ np.diag(adiabatic_energies[n])
```

up to numerical precision.

The columns of `adiabatic_vectors[n]` are electronic states. The function
uses maximum-overlap assignment and sign alignment against point `n-1`.

---

## 4. Calculate derivative couplings

```python
from nonadiabatic_dynamics import (
    finite_difference_derivative_couplings_1d,
    hellmann_feynman_derivative_couplings,
)

tau_hf = hellmann_feynman_derivative_couplings(
    adiabatic_energies,
    adiabatic_vectors,
    potential_derivative,
)[:, 0]

tau_fd = finite_difference_derivative_couplings_1d(
    grid.x,
    adiabatic_vectors,
)
```

The matrix element

```python
tau_hf[n, 0, 1]
```

represents

$\langle \phi_0(x_n) \mid \partial/\partial x\, \phi_1(x_n) \rangle$.

For real orthonormal states,

```python
tau_hf[n, 1, 0] == -tau_hf[n, 0, 1]
```

up to floating-point precision.

---

## 5. Integrate the adiabatic-to-diabatic transformation

```python
from nonadiabatic_dynamics import (
    integrate_adt_path,
    transform_adiabatic_to_diabatic,
)

initial_adt = adiabatic_vectors[0].T

adt = integrate_adt_path(
    grid.x,
    tau_hf,
    initial_adt,
)

reconstructed_potential = transform_adiabatic_to_diabatic(
    adiabatic_energies,
    adt,
)
```

The update performed internally is

```python
tau_mid = 0.5 * (tau[n] + tau[n + 1])
A_next = scipy.linalg.expm(-tau_mid * dx) @ A_current
```

followed by a polar re-orthogonalization to remove roundoff drift.

## 6. Prepare a Gaussian on the lower adiabatic surface

```python
from nonadiabatic_dynamics import (
    gaussian_wavepacket_1d,
    prepare_adiabatic_wavepacket_1d,
)

scalar_packet = gaussian_wavepacket_1d(
    grid.x,
    center=-8.0,
    width=0.70,
    momentum=12.0,
    dx=grid.dx,
)

psi_initial = prepare_adiabatic_wavepacket_1d(
    scalar_packet,
    adiabatic_vectors,
    state=0,
    dx=grid.dx,
)
```

`scalar_packet` has shape `(N,)`. The coupled diabatic wavefunction has shape

```python
psi_initial.shape == (2, N)
```

and is constructed from

$\psi_a(x,0) = U_{a0}(x) g(x)$.

## 7. Precompute the split-operator factors

```python
from nonadiabatic_dynamics import potential_propagator_2x2

mass = 1000.0
dt = 0.20

potential_half_step = potential_propagator_2x2(
    potential,
    0.5 * dt,
)

kinetic_full_step = np.exp(
    -1j * grid.k**2 * dt / (2.0 * mass)
)
```

The potential factor has shape `(N,2,2)`. The kinetic factor has shape `(N,)`.

---

## 8. Apply one FFT Strang step

```python
from nonadiabatic_dynamics import split_operator_step_1d

psi = split_operator_step_1d(
    psi,
    potential_half_step,
    kinetic_full_step,
)
```

The implementation is equivalent to

```python
psi = apply_local_matrix(potential_half_step, psi)

psi_k = np.fft.fft(psi, axis=-1)
psi_k *= kinetic_full_step[np.newaxis, :]
psi = np.fft.ifft(psi_k, axis=-1)

psi = apply_local_matrix(potential_half_step, psi)
```

The matrix multiplication in coordinate space is performed with `einsum`:

```python
np.einsum("xab,bx->ax", potential_half_step, psi)
```

---

## 9. Build the full direct Hamiltonian

```python
from nonadiabatic_dynamics import build_direct_hamiltonian_1d

hamiltonian = build_direct_hamiltonian_1d(
    grid.k,
    mass,
    potential,
)
```

For $N$ points,

```python
hamiltonian.shape == (2 * N, 2 * N)
```

The diagonal electronic blocks contain the Fourier-spectral kinetic matrix and
the corresponding diagonal potential. The off-diagonal blocks contain the
coordinate-diagonal electronic coupling.

---

## 10. Diagonalize and propagate exactly within the finite grid

```python
from nonadiabatic_dynamics import (
    diagonalize_hamiltonian,
    propagate_from_eigendecomposition,
)

eigenvalues, eigenvectors = diagonalize_hamiltonian(hamiltonian)

psi_direct = propagate_from_eigendecomposition(
    psi_initial,
    times=[0.0, 100.0, 200.0],
    eigenvalues=eigenvalues,
    eigenvectors=eigenvectors,
    spatial_shape=(grid.x.size,),
)
```

Internally,

```python
coefficients = eigenvectors.conj().T @ psi_initial.reshape(-1)

psi_t = eigenvectors @ (
    np.exp(-1j * eigenvalues * time) * coefficients
)
```

This contains no time-step approximation.

---

## 11. Calculate diabatic and adiabatic populations

```python
from nonadiabatic_dynamics import (
    adiabatic_populations_1d,
    diabatic_populations,
)

p_diabatic = diabatic_populations(psi, grid.dx)

p_adiabatic = adiabatic_populations_1d(
    psi,
    adiabatic_vectors,
    grid.dx,
)
```

The adiabatic transformation is performed pointwise:

```python
psi_ad = np.einsum(
    "xai,ax->ix",
    adiabatic_vectors,
    psi,
)
```

and then integrated over the nuclear coordinate.

---

## 12. Compare FFT and direct propagation

```python
from nonadiabatic_dynamics.observables import phase_aligned_error

fidelity, error = phase_aligned_error(
    reference=psi_direct[-1],
    candidate=psi_fft[-1],
    volume_element=grid.dx,
)
```

The global phase is aligned before calculating the wavefunction error.

# Two-dimensional implementation

## 13. Create the 2D grid and potential

```python
from nonadiabatic_dynamics import (
    PeriodicGrid2D,
    linear_vibronic_coupling_2d,
)

grid = PeriodicGrid2D.create(
    nx=64,
    ny=64,
    x_min=-8.0,
    x_max=8.0,
    y_min=-8.0,
    y_max=8.0,
)

x, y = np.meshgrid(grid.x, grid.y, indexing="xy")
potential, derivatives = linear_vibronic_coupling_2d(x, y)
```

The potential shape is

```python
potential.shape == (64, 64, 2, 2)
```

and the derivative shape is

```python
derivatives.shape == (64, 64, 2, 2, 2)
```

where the first matrix-adjacent index selects $x$ or $y$.

## 14. Construct the 2D kinetic phase

```python
kx, ky = np.meshgrid(grid.kx, grid.ky, indexing="xy")

kinetic_energy = (
    kx**2 / (2.0 * mass_x)
    + ky**2 / (2.0 * mass_y)
)

kinetic_step = np.exp(-1j * kinetic_energy * dt)
```

## 15. Apply the 2D split step

```python
from nonadiabatic_dynamics import split_operator_step_2d

psi = split_operator_step_2d(
    psi,
    potential_half_step,
    kinetic_step,
)
```

The kinetic operation uses

```python
psi_k = np.fft.fftn(psi, axes=(-2, -1))
psi_k *= kinetic_step[np.newaxis, :, :]
psi = np.fft.ifftn(psi_k, axes=(-2, -1))
```

## 16. Build a tiny direct 2D benchmark

```python
from nonadiabatic_dynamics import build_direct_hamiltonian_2d

hamiltonian_2d = build_direct_hamiltonian_2d(
    grid.kx,
    grid.ky,
    mass_x,
    mass_y,
    potential,
)
```

The direct matrix dimension is

$$
2 N_x N_y.
$$

This is why the example uses a separate $14\times 14$ direct benchmark rather
than diagonalizing the physically more useful $64\times 64$ FFT grid.

# Convergence study

Run

```bash
python examples/05_convergence_study_1d.py
```

The script compares several split-operator time steps against the same direct
finite-grid solution and fits

$$
\log \epsilon = p \log \Delta t + \mathrm{constant}.
$$

For a converged Strang implementation, the fitted global order should approach

$$
 p = 2.
$$
